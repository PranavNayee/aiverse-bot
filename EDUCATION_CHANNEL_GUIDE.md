## 🔧 How It Works (Technical)

### Daily Workflow

1. **8:00 AM IST** - GitHub Actions triggers `daily.yml`

2. **Lesson Selection** (`syllabus.py`)
   - Checks if weekend (fun fact) or weekday (lesson)
   - Gets next lesson from syllabus
   - Loads lesson metadata

3. **Script Generation** (`lesson_script.py`)
   - AI generates Hinglish script using Groq
   - Validates structure (hook, segments, CTA)
   - Returns narration + visual instructions

4. **Animation Creation** (`animations.py`)
   - Generates code-based visuals:
     * Title card (fade-in text)
     * Neural networks (animated nodes)
     * Process flows (step diagrams)
     * Text animations (typewriter/fade)
   - No AI image generation needed!

5. **Voice Synthesis** (`voice.py`)
   - Converts Hinglish text to speech
   - Uses `en-IN-PrabhatNeural` voice
   - Generates MP3 audio

6. **Video Assembly** (`lesson_main.py`)
   - Combines animations + voice
   - Adds background music
   - Creates final 45-75s reel

7. **Caption Generation** (`captions.py`)
   - Builds optimized caption
   - Adds key terms
   - Includes CTAs
   - Smart hashtags

8. **Publishing** (`instagram.py`)
   - Posts to Instagram automatically
   - Sends Telegram notification
   - Records in history
