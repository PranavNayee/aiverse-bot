AIVerse Bot - Privacy Policy

Last updated: 7 November 2026

AIVerse Bot ("the app") is a personal automation operated by the owner of the AIVerse channel. It generates short educational videos and uploads them to the owner's own YouTube channel and Instagram account.

What data the app accesses

  • With the owner's permission (Google OAuth), the app uses the YouTube Data API to upload videos to the owner's own channel and to read basic information about that channel.
  • The app does not access, collect or store data about any other person or account.

How data is stored

The OAuth credentials are stored as encrypted secrets in the owner's private GitHub Actions settings and are used only to publish the owner's videos. Generated videos are stored in the owner's own cloud storage.

Sharing

No data is sold, shared with third parties or used for advertising.

Use of Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue on GitHub.
